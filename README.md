# Мянганбуу: засварын ажлын сайт

Энэ сайт таны хийсэн ажлыг харуулж, захиалагчаас хүсэлт хүлээн авч, үнийн санал гаргахад тусална. Бүгдийг утаснаасаа хийж болно.

---

## 1. Удирдлага руу орох

1. Утасныхаа хөтөч дээр сайтын хаягийн ард `/admin` гэж бичнэ. Жишээ нь: `myanganbuu.mn/admin`
2. Нэвтрэх нэр, нууц үгээ оруулаад **Нэвтрэх** товчийг дарна.
3. Нэг удаа нэвтэрсэн бол 30 хоног дахин нэвтрэх шаардлагагүй.

**Утасны нүүр дэлгэцэнд нэмэх (зөвлөмж):** Хөтчийн цэсээс (⋮) **«Нүүр дэлгэцэнд нэмэх»** гэдгийг дарна. Дараа нь «Мянганбуу» гэсэн дүрс дээр дарахад шууд удирдлага нээгдэнэ. Дүрсийг удаан дарвал «Ажил үзүүлэх», «Хүсэлтүүд» гэсэн товчлол гарна.

Доод талд дөрвөн товч бий:

| Товч | Юу хийх вэ |
| --- | --- |
| **Ажил** | Хийсэн ажлаа нэмэх, засах |
| **Хүсэлт** | Захиалагчдаас ирсэн хүсэлт |
| **Үнэ** | Үнийн жагсаалт, үнийн санал |
| **Тохиргоо** | Нүүр хуудас, Миний тухай, хуваалцах, мэдэгдэл, холбоо барих хаяг |

---

## 2. Шинэ ажил нэмэх

Ажил дуусмагц зургаа оруулахад хангалттай.

1. **Ажил** → **Шинэ ажил** товч.
2. **Ажлын нэр** бичнэ. Жишээ нь: *Баянзүрх, 2 өрөө байрны угаалгын өрөө*.
3. **Аль өрөө вэ?** гэдгээс сонгоод **Үргэлжлүүлэх** дарна.
4. **Зураг нэмэх** товчийг дараад утасныхаа цомгоос зургуудаа сонгоно. Олон зургийг нэг дор сонгож болно.
   - Зураг бүрийн доор илгээж буй явц харагдана.
   - Том зургийг утас өөрөө жижигрүүлж илгээдэг тул мобайл дата бага зарцуулна.
   - Хэвтээ, босоо эргэсэн зургийг сайт өөрөө засна.
   - Амжилтгүй болсон зураг дээр **Дахин** дарна.

### Өмнө ба дараах зургийг хослуулах

Энэ бол сайтын хамгийн чухал хэсэг. Захиалагч засварын өмнөх ба дараах зургийг гулсуулж харьцуулна.

1. **Хослуулах** товчийг дарна.
2. Засварын **ӨМНӨХ** зургийг дарна.
3. Дараа нь мөн тэр газрын засварын **ДАРААХ** зургийг дарна.
4. «Хослууллаа» гэж гарна. Хос бүр дугаартай харагдана.

Хамгийн сайн хосыг **Гол болгох** дарж сонгоно. Энэ нь ажлын хуудасны дээд хэсэгт, нүүр хуудсанд харагдана.

### Зургийг засах, дараалал солих

- Зураг дээр дарахад засах цонх гарна. Тэндээс:
  - **Зургийн төрөл** солих (Зураг, Өмнө, Дараа, Ажлын явц)
  - **Зургийн тайлбар** бичих. Харж чаддаггүй хүмүүст уншиж өгөх, мөн Гүүглд олдоход тусална.
  - **Нүүр зураг болгох**
  - **Дээш / Доош** зөөх, **Устгах**
- Дараалал солихдоо зургийг **удаан дараад** чирнэ.
- **Ажлын явц** гэсэн зургийн огноо, бичгийг оруулбал ажлын хуудсанд он цагийн дарааллаар харагдана.

### Мэдээлэл бөглөж, нийтлэх

1. Дээд талын **Мэдээлэл** таб руу орно.
2. Тайлбар, хийсэн ажлууд, дүүрэг, талбай (м²), хугацаа (хоног), дууссан огноог бөглөнө.
3. **Сайтад нийтлэх** товчийг асаана. Унтраалттай бол зөвхөн та харна.
4. Онцлох ажил бол **Нүүр хуудсанд гаргах** асаана (4 хүртэл).
5. Доод талын **Хадгалах** товчийг дарна.

Нийтэлсэн ажлын доор **Фэйсбүүкт хуваалцах** товч гарна. Холбоосыг фэйсбүүкт тавихад зураг, гарчиг нь автоматаар гарна. Нийтэлсний дараа гарчгаа солиход холбоос өөрчлөгдөхгүй.

---

## 3. Үнийн жагсаалт шинэчлэх

Үнийн жагсаалт зөвхөн танд харагдана. Үнийн санал гаргахад эндээс сонгоно.

1. **Үнэ** → **Миний үнийн жагсаалт**.
2. Мөр дээр дарж засна:
   - **Ажлын нэр**: жишээ нь *Хана, шалны хавтан тавих*
   - **Нэгж үнэ (₮)**: жишээ нь *45000*
   - **Нэгж**: м², ш, цэг, өдөр гэх мэт
   - **Ангилал**: Хавтан, Цахилгаан гэх мэт. Сонгоход бүлэглэж харуулна.
3. **Хадгалах** дарна.
4. Шинэ ажил нэмэх бол **Ажил нэмэх** товч.

> Анхны жагсаалтын үнэ бол жишээ. Өөрийн үнээр заавал сольж бичээрэй.
>
> Үнийг өөрчлөхөд өмнө нь илгээсэн үнийн санал өөрчлөгдөхгүй.

---

## 4. Үнийн санал гаргаж илгээх

1. **Үнэ** → **Шинэ үнийн санал**. Эсвэл хүсэлт дотроос **Үнийн санал гаргах** дарвал захиалагчийн мэдээлэл автоматаар бөглөгдөнө.
2. Захиалагчийн нэр, хаягийг бичнэ.
3. **Жагсаалтаас нэмэх** дарж хийх ажлуудаа сонгоно. Хэд хэдийг зэрэг сонгож болно.
4. Ажил бүрийн **тоо хэмжээг** **−** / **+** товчоор эсвэл гараар бичнэ (жишээ нь 22,5).
5. Тухайн захиалагчид өөр үнэ хэлэх бол **Нэгж үнийг** тэр дор нь сольж болно.
6. Жагсаалтад байхгүй ажил бол **Өөр мөр нэмэх**.
7. Материалын үнэ оруулсан бол **Материалын үнэ орсон**-ыг асаана.
8. **Хадгалах** дарна. Доод талд **Нийт** дүн харагдана.
9. **Захиалагчид илгээх** дарж мессенжер эсвэл вайбераар холбоосоо илгээнэ. Захиалагч ажил бүрийн үнэ, нийт дүн, хүчинтэй хугацааг харна, PDF татаж авч болно.

---

## 5. Хүсэлт хүлээн авах

Захиалагч сайтын маягтыг бөглөхөд **Хүсэлт** хэсэгт ирнэ.

**Утсандаа мэдэгдэл авах:** **Тохиргоо** → **Мэдэгдэл асаах** → хөтөч асуухад **Зөвшөөрөх**. Дараа нь **Туршилтын мэдэгдэл илгээх** дарж шалгана.

Хүсэлт дотор:

- **Мессенжер нээх / Вайбер нээх** товч захиалагчтай шууд чат нээнэ.
- Захиалагчийн илгээсэн зургууд харагдана.
- Төлөвийг нэг дарж солино: **Шинэ → Холбогдсон → Үнэ өгсөн → Ажил эхэлсэн → Дууссан**.
- **Миний тэмдэглэл** зөвхөн танд харагдана.

---

## 6. Захиалагчид ажлаа үзүүлэх

Захиалагчтай уулзахдаа утсаараа ажлаа харуулна.

1. Хөтөч дээр `/uzuulekh` хаягийг нээнэ (эсвэл дүрсийг удаан дараад **Ажил үзүүлэх**).
2. Гэрээсээ гарахаасаа өмнө **Офлайнд хадгалах** дарна. Ингэснээр сүлжээгүй подвал, шинэ байранд ч зургууд харагдана.
3. Ажил дээр дараад, **Өмнөх / Дараах** товчоор шилжинэ. Өмнө/дараах зургийг хуруугаараа гулсуулна.

---

## 7. Тохиргоо

**Тохиргоо** хэсгийн дээд талд хоёр хуудас бий.

### Нүүр хуудас

- **Захиалгын төлөв**: нүүр хуудасны дээд хэсэгт ногоон цэгтэй харагдах богино бичиг. Жишээ нь *Зуны фасадын захиалга авч байна*. Хоосон орхивол харагдахгүй.
- **Нүүр хуудасны гол зураг**: аль ажлын өмнө/дараа зураг нүүрэнд гарахыг сонгоно.
- **Онцлох ажлууд**: нүүр хуудсанд гарах 4 хүртэл ажлаа сонгож, **Дээш / Доош** товчоор дарааллыг тогтооно. Сонгоогүй бол хамгийн сүүлийн ажлууд гарна.

### Миний тухай

Сайтын «Миний тухай» хуудас.

- **Гарчиг**, **Танилцуулга**: өөрийгөө, хэрхэн ажилладгаа бичнэ. Догол мөрийг хоосон мөрөөр тусгаарлана.
- **Туршлага (жил)**: хэдэн жил энэ ажлыг хийж байгаа вэ.
- **Зургууд**: өөрийн зураг, ажлын үеийн, багийнхаа зургийг нэмнэ. Эхний зураг нь хуудасны гол зураг болно. **Гол зураг болгох** дарж сольж болно.

### Ажлуудаа хуваалцах

Ажлын төрөл бүр сайтад өөрийн хуудастай. Жишээ нь зөвхөн фасадын ажлууд. **Фэйсбүүкт хуваалцах** дарахад тухайн төрлийн ажлуудын холбоос зурагтайгаа фэйсбүүкт гарна. **Хуваалцах** нь мессенжер, вайбераар илгээнэ.

### Бусад

- **Мэдэгдэл**, **Холбоо барих** (фэйсбүүк, вайбер), **Гарах**.

## 8. Сайтын бичвэрийг өөрчлөх

Сайтад харагдах бүх үг нэг файлд байна:

- `src/messages/mn.ts`: товч, гарчиг, тайлбар гэх мэт бүх бичвэр
- `src/content/services.ts`: үйлчилгээний хуудсуудын тайлбар

Зөвхөн хашилтан доторх үгийг засна. Засвар хийсний дараа сайтыг дахин байршуулна (доорх техникийн хэсгийг үз).

---

## Техникийн хэсэг (сайт хариуцагчид)

**Технологи:** Next.js 16, Prisma 7 + MySQL, Tailwind 4, sharp, PM2, nginx.

### Орчны хувьсагч

`.env.example`-ийг хуулж `.env` болгоод бөглөнө. Production-д бүх `.env` агуулгыг GitHub-ийн `PROD_SECRETS` нууцад хадгална. Deploy үед серверт бичигдэнэ. Гол утгууд:

| Хувьсагч | Тайлбар |
| --- | --- |
| `DATABASE_URL` | `mysql://appuser:НУУЦ_ҮГ@localhost:3306/appdb` (сервер дээр localhost) |
| `SITE_URL` | `https://...` бүтэн хаяг. Фэйсбүүкийн зураг, sitemap-д хэрэгтэй. |
| `UPLOAD_DIR` | `/home/cloudmn/apps/myanganbuu-data/uploads` (git-ээс гадна) |
| `SESSION_SECRET` | 32+ тэмдэгт санамсаргүй мөр |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` | `npx web-push generate-vapid-keys` |

### Анх суулгах

```bash
npm ci
npx prisma migrate deploy
npm run admin:create -- <нэр> <нууц-үг>   # нэвтрэх эрх үүсгэх / нууц үг солих
npm run db:seed                            # эхний 8 ажил (prisma/seed-images), үнийн жагсаалт
npm run build
pm2 startOrReload ecosystem.config.cjs && pm2 save
```

Апп `127.0.0.1:4000` дээр ажиллана. nginx-ийн тохиргоонд:

```nginx
client_max_body_size 50m;          # утасны том зураг
location / {
  proxy_pass http://127.0.0.1:4000;
  proxy_set_header Host $host;
  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  proxy_set_header X-Forwarded-Proto $scheme;
  proxy_buffering off;             # хуудсыг хэсэгчлэн дамжуулахад
}
```

### Deploy

`main` салбар руу push хийхэд `.github/workflows/deploy.yml` сервер дээр: код татах → `.env` бичих → `npm ci` → `prisma migrate deploy` → `npm run build` → `pm2 startOrReload`.

### Өгөгдлийн сангийн өөрчлөлт

DB хэрэглэгч shadow database үүсгэх эрхгүй тул:

```bash
# prisma/schema.prisma-г засаад:
npm run db:diff -- нэр      # prisma/migrations/... SQL үүсгэнэ, шалгаарай
npm run db:deploy           # хэрэгжүүлэх
```

### Нөөц хуулбар

`scripts/backup.sh` нь MySQL болон зургуудыг өдөр бүр хадгалж, 14 хоног байлгана. Суулгах заавар файлын эхэнд бий:

```cron
30 3 * * * /home/cloudmn/apps/myanganbuu/scripts/backup.sh >> /home/cloudmn/backups/myanganbuu/backup.log 2>&1
```

### Шалгах

```bash
npm run typecheck && npm run lint
npm run check:glyphs                 # фонтод Ө, Ү, ₮ байгаа эсэх, урт зураас ашиглаагүй эсэх
node scripts/check-js-budget.mjs http://localhost:4000   # нийтийн хуудасны JS ≤ 150 КБ
```
